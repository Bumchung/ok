# Istanbul + Doha Family Trip 2027

이스탄불 7박 뒤 도하 3박을 붙이는 조건부 실행 앱입니다. IST-DOH, DOH-ICN, DOH-LAX 노선은 존재하지만 2027년 3월 31일 수요일 DOH-LAX 직항이 실제 판매될 때만 성립합니다.

## 판단 원칙

- 날짜까지 맞아야 직항 조건을 통과한 것으로 봅니다.
- 현재 화, 목, 토, 일 패턴이 유지되면 수요일 출발인 이 안은 탈락합니다.
- 공식 Stopover 가격은 1인 3박, 2인 1실 시작가이며 어린이 3명과 4실 총액이 아닙니다.
- 도착과 출발을 비우고 박물관 하루, Katara와 아이 체험 하루만 둡니다.
- 날짜 게이트가 실패하면 환승이나 추가 숙박으로 억지로 맞추지 않고 두바이안으로 돌아갑니다.
