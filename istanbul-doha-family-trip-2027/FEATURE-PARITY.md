# 이스탄불 기준 기능 동등성

| 화면 | 이스탄불 원안 | 이스탄불 + 도하 |
| --- | --- | --- |
| 가족 동선 | ICN과 LAX에서 IST 합류 | IST 7박 뒤 DOH, 목표일에만 ICN/LAX 직항 분리 |
| 숙소 | 장기 체류 구조 | 공식 Stopover 예시 호텔 12곳, 레지던스 6곳 |
| 가격 | 관측가와 계산 경계 | 세 카테고리 가격과 2인 1실 조건, 목표일 총액 미확정 |
| 일정 | 일별 카드 | 3박 4일, 두 속도와 LAX 실패 조건 |
| 장소 | 권역별 카드 | 30곳, 검색과 필터 |
| 식사 | 가족 운영 조건 | 음식점 20곳, 카페 10곳 |
| 지도 | 필터와 상세 팝업 | 동일 기능, 위치 기반 가까운 순서 |
| 도구 | CSV, KML, ICS, 로컬 질문 | 동일 기능 |

도하안의 반증 조건은 단 하나로 먼저 좁힙니다. 2027년 3월 31일 DOH-LAX 직항이 판매되지 않으면 나머지 장점과 무관하게 탈락입니다.
