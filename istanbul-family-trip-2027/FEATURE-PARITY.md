| 기능 | Istanbul Together 2027 | 판단 |
| --- | --- | --- |
| D-day와 오늘 허브 | 계획, 여행, 완료 모드 자동 전환 | 동등 |
| 지금 가까운 곳 | 현재 위치 또는 숙소 기준으로 6곳 거리순 정렬 | 동등 |
| 가족 출발 정보 | ICN팀과 LAX팀을 별도 카드로 표시 | 동등 |
| 숙소 비교 | 4개 후보, 동일한 기준과 공식 링크 | 강화, 한 집 조건 추가 |
| 날짜별 일정 | 3월 20일부터 31일까지 날짜 탭과 전체 목록 | 동등 |
| Plan A, B, C | 오늘 가기, 비 오면, 힘들면 | 동등 |
| 날짜별 식사 | 매일 9인 식사 운영 원칙 | 동등 |
| 날씨 | 공식 장기 평균, 예보 가능 시 Open-Meteo 자동 전환 | 동등 |
| 장소 가이드 | 24개 실제 후보와 제외 사유 | 의도적 축소, 숫자 채우기 제거 |
| 사진과 링크 | 장소별 로컬 사진 24개, 정확한 출처, fallback 0 | 강화 |
| 후기 장단점 | 장소별 칭찬 2개 이상, 반복 불만, 아이 셋 사용법 | 강화 |
| 동선 지도 | 실제 CARTO/OSM 타일, 장소 핀, 확대와 축소, Google Maps | 강화 |
| 검색과 필터 | 이름, 지역, 분류, 후기 불만, 아이 조건, 제외 이유 검색 | 강화 |
| 질문 게시판 | localStorage 보존, 앱 내장 답변 | 동등 |
| 원격 AI | GPT와 Claude 병렬, 웹 검색, 출처, 속도 제한, CORS | 배포 전 코드 동등 |
| 캘린더 | 날짜별 Google Calendar 링크와 12일 전체 ICS | 강화 |
| 데이터 내보내기 | 브라우저 CSV, KML, ICS | 강화 |
| 비용과 예약 부록 | 예산 원칙, 예약 순서, 허위 총액 방지 | 동등 |
| 출처 부록 | 공식 출처와 확인일 | 강화 |

앱은 이 폴더 안의 파일만으로 실행된다. 원격 AI 서버가 없어도 내장 여행 자료 검색은 작동하며, 공개 배포 상태는 50문항 감사 스크립트로 별도 확인한다.
