# Sydney 앱 대비 기능 동등성

| 기능 | Istanbul Together 2027 | 판단 |
| --- | --- | --- |
| D-day와 오늘 허브 | 계획, 여행, 완료 모드 자동 전환 | 동등 |
| 가족 출발 정보 | ICN팀과 LAX팀을 별도 카드로 표시 | 동등 |
| 숙소 비교 | 4개 후보, 동일한 기준과 공식 링크 | 강화, 한 집 조건 추가 |
| 날짜별 일정 | 3월 20일부터 31일까지 날짜 탭과 전체 목록 | 동등 |
| Plan A, B, C | 기본안, 우천안, 저강도안 | 동등 |
| 날짜별 식사 | 매일 9인 식사 운영 원칙 | 동등 |
| 날씨 | 공식 장기 평균, 예보 가능 시 Open-Meteo 자동 전환 | 동등 |
| 장소 가이드 | 24개 실제 후보와 제외 사유 | 의도적 축소, 숫자 채우기 제거 |
| 사진과 링크 | Wikimedia 사진, 공식 페이지, 지도, 실패 폴백 | 동등 |
| 동선 지도 | 숙소와 핵심 관광지 핀, 선택 상세 | 동등 |
| 검색과 필터 | 검색, 지역, 분류, 우천, 에너지 조합 | 동등 |
| 질문 게시판 | localStorage 보존, 앱 내장 답변 | 동등 |
| 원격 AI | GPT와 Claude 병렬, 웹 검색, 출처, 속도 제한, CORS | 배포 전 코드 동등 |
| 데이터 내보내기 | 브라우저 CSV와 KML, 정적 산출물 | 동등 |
| 비용과 예약 부록 | 예산 원칙, 예약 순서, 허위 총액 방지 | 동등 |
| 출처 부록 | 공식 출처와 확인일 | 강화 |

공개 배포와 원격 AI 서버 연결은 코드 기능이 아니라 외부 운영 상태다. 현재 폴더는 GitHub Pages 정적 앱으로 바로 배포 가능하고, `api/ask.mjs`는 별도 Vercel 프로젝트에 배포할 수 있다.
