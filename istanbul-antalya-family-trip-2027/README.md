# Istanbul + Antalya, Family Trip 2027

성인 6명과 만 9세, 7세, 6세 어린이 3명의 이스탄불 가족여행에 안탈리아 3박을 더하는 대안 판단 페이지입니다.

공개 주소: <https://bumchung.github.io/ok/istanbul-antalya-family-trip-2027/>

## 결론

- 이스탄불 5박, 안탈리아 3박, 이스탄불 2박
- 이스탄불 숙소와 본짐은 10박 동안 유지
- 안탈리아 왕복은 IST 출도착 국내선만 사용
- 안탈리아는 해수욕이 아니라 온화한 산책, 로마 유적, 바다 풍경과 우천 실내 대안으로 선택
