# 두바이 페이지 자체 감사

## 근거 경계

- 현재 정기 직항 존재와 빈도는 항공사 공식 페이지로 확인했지만 2027년 3월 편명과 9석은 미확정입니다.
- 추천 다구간 총액은 공개하지 않았습니다. 서로 다른 왕복 공개가를 더해 가짜 합계로 만들지 않았습니다.
- 호텔 6곳은 같은 목표 기간의 10박 관측값을 3박으로 단순 환산했고, 나머지는 비목표일 시작가 또는 도시 ADR입니다.
- 장소 30곳은 공식 관광기관과 운영기관 자료를 우선했습니다.
- WMO 장기 평년값은 2027년 예보가 아닙니다.

## 완료 게이트

- 데이터, 기능, 이미지 무결성 테스트 통과
- 78개 로컬 이미지의 고유 해시와 출처 확인
- 1440px와 390px 실제 렌더링에서 가로 넘침, 깨진 이미지와 콘솔 오류 없음
- 공개 URL과 핵심 자산 HTTP 200 확인
