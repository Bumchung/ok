# Istanbul + Dubai Family Trip 2027

ICN팀 5명과 LAX팀 4명이 이스탄불에서 합류해 7박한 뒤, 같은 IST-DXB 직항으로 두바이에 가서 3박하고 DXB에서 각자 직항으로 귀국하는 실행 앱입니다.

## 판단 원칙

- 이스탄불은 고정하고 두바이를 마지막 3박으로만 붙입니다.
- IST-DXB, DXB-ICN, DXB-LAX 세 직항이 목표일에 모두 판매될 때만 실행합니다.
- 추천 다구간 실가격과 9인 4실 실가격이 없는 상태에서 가짜 총액을 만들지 않습니다.
- 10박 목표 기간 관측가, 비목표일 시작가와 시장 ADR을 서로 다른 근거 등급으로 표시합니다.
- 도착과 출발을 비우고 온전한 이틀만 일정화합니다.
