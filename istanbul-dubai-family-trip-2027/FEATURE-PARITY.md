# 이스탄불 기준 기능 동등성

| 화면 | 이스탄불 원안 | 이스탄불 + 두바이 |
| --- | --- | --- |
| 가족 동선 | ICN과 LAX에서 IST 합류 | IST 7박 뒤 9명 공동편, DXB에서 ICN/LAX 직항 분리 |
| 숙소 | 장기 체류 구조 | 호텔 12곳, 레지던스 6곳, 4실 기준 |
| 가격 | 관측가와 계산 경계 | 호텔 12곳 가격 상태, 다구간 항공은 미확정 표시 |
| 일정 | 일별 카드 | 3박 4일, 두 속도와 실패 조건 |
| 장소 | 권역별 카드 | 30곳, 검색과 필터 |
| 식사 | 가족 운영 조건 | 음식점 20곳, 카페 10곳 |
| 지도 | 필터와 상세 팝업 | 동일 기능, 위치 기반 가까운 순서 |
| 도구 | CSV, KML, ICS, 로컬 질문 | 동일 기능 |

두바이안의 반증 조건은 세 직항 중 하나의 목표일 미판매, 9석 공동편 실패, 4실 배치 실패 또는 실제 다구간 차액의 가족 한도 초과입니다.
