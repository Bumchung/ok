# 이스탄불과 안탈리아 기능 비교

안탈리아는 이스탄불 앱의 데이터 양을 그대로 복제하지 않았습니다. 10박 도시 체류와 3박 분기 여행의 의사결정 밀도를 맞췄습니다.

| 평가 화면 | 이스탄불 원안 | 안탈리아 대안 |
| --- | --- | --- |
| 가족과 이동 | ICN과 LAX 합류 | IST와 AYT 왕복 2구간 |
| 숙소 | 한집형과 호텔 30곳 | 호텔 12곳과 레지던스 구조 후보 6곳 |
| 가격 근거 | 관측값과 미관측값 분리 | 2027년 미관측값을 숫자 없이 표시 |
| 일정 | 10박, 두 속도 | 3박 4일, 두 속도 |
| 장소 | 100곳 | 30곳 |
| 식음 | 음식점 60곳과 카페 40곳 | 음식점 20곳과 카페 10곳 |
| 지도 | 장소, 음식점, 카페 레이어 | 장소, 음식점, 카페 레이어 |
| 현장 도구 | 주변 정렬, 질문, CSV/KML/ICS | 동일 |
| 실패 조건 | 휴관, 체력, 날씨와 이동 | 국내선, 실내 수영장, 4실 배치, 16석급 차량까지 추가 |

안탈리아 선택을 중단하는 조건은 두 가지입니다. 좋은 시간대의 IST 왕복을 확보하지 못하거나, 어린이의 3월 실내 수영장 이용을 숙소가 서면으로 확약하지 못하면 이스탄불 10박 원안을 유지합니다.
