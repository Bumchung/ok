- 6-10: 금지한 기획서 말투 검사, 장소별 후기 장단점, 공식 정보와 후기 출처 분리, 주변 추천, 실제 지도, 날짜 사진, 질문 검색, Google Calendar와 ICS
- 11-15: 10박과 12개 날짜 분리, 이스탄불과 다른 숙소와 동선과 장소, 2027년 미확정 정보 표시, 재작성 프롬프트 질문 50개 고정
- 16-20: 성인 6명과 아이 3명, 만 9세와 7세와 6세, ICN/LAX 분리, 4베드룸 한집 우선, 예산 상한 없음
- 21-25: 수영과 낮잠과 차량 시간을 반영한 하루 한 곳 원칙, 도착일 체크인만, 회복일, 사막 사파리와 Abu Dhabi 제외
- 26-30: 장기 기후와 실제 예보 구분, 강풍과 워터파크 제한, 날짜별 비 오면과 힘들면, 12일치 아홉 명 식사
- 31-35: 가족 조건에 맞지 않는 장소 제외, 후기 칭찬과 불만 동시 표시, 확인일, 정확한 장소 사진과 출처, 정직한 대체문구
- 36-40: 위치 권한 실패 대응, CARTO/OSM 지도 타일, 후기 내용 검색, 서버 없는 질문 답변, 비밀키 없는 Google Calendar 링크
- 41-45: 12개 VEVENT가 든 ICS, CSV와 KML, 모바일 하단 이동, 키보드와 reduced motion, 이미지와 외부 API 실패 대응
- 46-50: 앱 폴더 안의 자체 런타임, 항공편과 객실 재고 미확정 표시, 렌더링 사진 오류 0, 시각 판정 통과, 공개 파일 HTTP 검증 절차

## 이번 감사에서 실제로 고친 것

- 장소 검색이 후기 불만, 유모차 보관, 아이 조건, 빼야 할 상황까지 찾도록 넓혔다.
- 15개 장소 사진을 로컬 캐시로 바꾸고 Burj Khalifa 카드의 잘못된 Burj Al Arab fallback을 정확한 사진으로 교체했다.
- 질문 답변의 `저강도`, `기본 단위`, `강합니다`, `기본값` 같은 기획서 문장을 가족 대화처럼 다시 썼다.
- 앱이 상위 공용 파일 없이 이 폴더만으로 실행되도록 자체 `trip-app.mjs`를 넣었다.
- 날짜별 Google Calendar 링크와 전체 일정 ICS를 함께 제공한다.
