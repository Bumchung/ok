# Istanbul + Warm Stop, Family Trip 2027

공개 주소: <https://bumchung.github.io/ok/warm-family-trip-2027/>

ICN팀 5명과 LAX팀 4명이 이스탄불을 고정하고 따뜻한 나라 하나를 추가할 때의 전체 동선, 방문 순서, 항공과 호텔 가격 기준을 비교합니다.

## 결론

- 3월 21일부터 28일까지 이스탄불 7박
- 3월 28일 아홉 명이 같은 IST→DXB편으로 이동
- 3월 28일부터 31일까지 두바이 3박
- 3월 31일 DXB에서 ICN과 LAX 직항으로 분리 귀국
- 도하는 LAX 운항일과 실제 다구간 가격이 더 좋을 때만 예비안

## 가격 원칙

- 두 출발지의 실제 다구간 항공권을 각각 한 검색으로 견적합니다.
- 기존 이스탄불 왕복과 다구간 견적의 차이를 추가 항공비로 봅니다.
- 서로 다른 편도 또는 왕복 공개가를 합쳐 허위 총액을 만들지 않습니다.
- 호텔 기준선은 객실 4실, 3박입니다.
