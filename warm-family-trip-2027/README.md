# Warm Meeting Point, Family Trip 2027

공개 주소: <https://bumchung.github.io/ok/warm-family-trip-2027/>

ICN팀 5명과 LAX팀 4명이 2027년 3월 20일부터 31일까지 튀르키예 대신 만날 따뜻한 목적지를 비교합니다.

## 판단 원칙

- 목적지 교체와 엄밀한 제3국 경유를 다른 질문으로 취급합니다.
- 평균 비행시간보다 더 긴 팀의 편도 시간과 두 팀 간 격차를 봅니다.
- 공개 운임은 목표일, 목표 기간, 다른 날짜 참고가를 분리합니다.
- 호텔 가격은 공개 시장 평균을 객실 4실, 10박으로 단순 환산한 기준선이며 결제 견적이 아닙니다.
- 결론을 뒤집는 조건과 예약 중단선을 함께 적습니다.
