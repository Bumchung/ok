# Cappadocia Family Trip 2027

이스탄불 10박 원안, 안탈리아 3박 대안과 같은 기능 밀도로 비교하는 카파도키아 3박 실행 앱입니다.

## 설계 원칙

- 열기구가 취소돼도 여행이 성립하도록 지상 일정을 먼저 설계합니다.
- 2027년 객실, 항공, 열기구 가격을 관측하지 못한 상태에서 정확한 가격처럼 쓰지 않습니다.
- 카파도키아를 한 도시로 다루지 않고 Göreme, Uçhisar, Ürgüp, Avanos와 남부 장거리 권역을 분리합니다.
- 동굴 객실은 분위기보다 창, 환기, 난방, 계단과 실제 침대 구조를 우선합니다.
- 3박 가족 기본 일정에는 지하도시 한 곳만 넣고 Ihlara와 다른 장거리 계곡은 제외합니다.
