# 이스탄불, 안탈리아와 카파도키아 기능 비교

카파도키아 앱은 3박이라는 짧은 체류에 맞게 데이터 양이 아니라 의사결정 밀도를 맞춥니다.

| 평가 화면 | 이스탄불 원안 | 안탈리아 대안 | 카파도키아 대안 |
| --- | --- | --- | --- |
| 가족과 이동 | ICN과 LAX 합류 | IST와 AYT 왕복 | IST에서 NAV 우선, ASR 비교 |
| 숙소 | 10박 장기 체류 | 실내 수영장과 연결 객실 | 창, 환기, 계단과 9인 실제 구조 |
| 가격 | 관측가와 계산 경계 | 2027년 미확인 | 2027년 미확인, 열기구 별도 |
| 일정 | 10박 일별 카드 | 3박, 두 속도 | 3박, 두 속도와 열기구 실패 경로 |
| 장소 | 권역별 장소 카드 | 30곳 | 30곳, 장거리와 위험 조건 표시 |
| 식사 | 가족 운영 조건 | 음식점 20곳, 카페 10곳 | 음식점 20곳, 카페 10곳 |
| 도구 | 검색, 지도, 내보내기 | 같은 기능 | 같은 기능 |

카파도키아 선택의 반증 조건은 명확합니다. 벌룬 없이도 가족 모두가 가고 싶어야 하고, 좋은 항공 시간대, 안전한 객실 배치와 3월 추위 수용이 동시에 성립해야 합니다.
